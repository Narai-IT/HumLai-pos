🖨️ คู่มือติดตั้ง Print Server

HumLai POS — โปรแกรมตัวกลางที่ส่งงานพิมพ์จากหน้าเว็บไปเครื่องพิมพ์ใบเสร็จ/ใบครัวในร้าน

สารบัญ
  1. Print Server คืออะไร
  2. สิ่งที่ต้องมี
  3. ติดตั้งครั้งแรก
  4. ตั้งค่าและทดสอบเครื่องพิมพ์
  5. อ่านสถานะการพิมพ์
  6. อัปเดตเวอร์ชันใหม่
  7. แก้ปัญหาที่พบบ่อย
  8. ไฟล์ในโฟลเดอร์
  9. ถอนการติดตั้ง

1. Print Server คืออะไร ทำไมต้องมี

เครื่องพิมพ์ใบเสร็จในวงแลน (LAN) รับงานผ่านพอร์ต 9100 ซึ่งเบราว์เซอร์ติดต่อเองไม่ได้ จึงต้องมีโปรแกรมตัวกลางเล็ก ๆ รันอยู่ในคอมพิวเตอร์ของร้าน คอยรับงานจากหน้าเว็บแล้วส่งต่อให้เครื่องพิมพ์

หน้าเว็บ POSเบราว์เซอร์
→
Print Serverคอมในร้าน พอร์ต 3001
→
เครื่องพิมพ์วงแลนร้าน พอร์ต 9100

Print Server ยังคอยดึงออเดอร์ที่ลูกค้าสั่งเองผ่าน QR มาพิมพ์ใบครัวให้อัตโนมัติด้วย (ถ้าเปิดสวิตช์ไว้ในหน้าตั้งค่าเครื่องพิมพ์)

ติดตั้งสาขาละ 1 เครื่อง ใช้เครื่องแคชเชียร์ก็ได้ — ขอให้เป็นเครื่องที่เปิดตลอดเวลาที่ร้านเปิด และต่อวงแลน/Wi-Fi เดียวกับเครื่องพิมพ์

2. สิ่งที่ต้องมี

รายการรายละเอียด
คอมพิวเตอร์ WindowsWindows 10 หรือ 11 อยู่วงแลนเดียวกับเครื่องพิมพ์
Node.jsรุ่น LTS (ฟรี) จาก https://nodejs.org — ติดตั้งครั้งเดียว
อินเทอร์เน็ตต้องใช้ตอนติดตั้งครั้งแรก (โหลดส่วนประกอบ ~5 MB) และตอนสั่งพิมพ์จากหน้าเว็บ
เครื่องพิมพ์เครื่องพิมพ์ความร้อน ESC/POS แบบต่อแลน (เช่น Epson TM, Xprinter) ตั้ง IP ไว้แล้ว
สิทธิ์ผู้ดูแลบัญชีที่ล็อกอินหลังบ้านได้ และเข้าเมนู ตั้งค่าเครื่องพิมพ์ ได้

3. ติดตั้งครั้งแรก

  1. ติดตั้ง Node.js
    เข้า https://nodejs.org → กดปุ่มดาวน์โหลดรุ่น LTS → เปิดไฟล์ที่ได้ → กด Next ไปเรื่อย ๆ จนเสร็จ (ค่าเริ่มต้นใช้ได้เลย)
  2. ดาวน์โหลด Print Server
    เปิดหน้าเว็บ POS → หลังบ้าน → ตั้งค่าเครื่องพิมพ์ → กดปุ่ม ⬇️ ดาวน์โหลด Print Server จะได้ไฟล์ humlai-print-server.zip
  3. แตกไฟล์
    คลิกขวาที่ไฟล์ zip → Extract All… (แตกไฟล์ทั้งหมด) → ตั้งที่เก็บเป็น C:\ → กด Extract
    จะได้โฟลเดอร์ C:\HumLai-Print-Server
    อย่าดับเบิลคลิกไฟล์ในหน้าต่าง zip ตรง ๆ ต้องแตกไฟล์ก่อนเสมอ และไม่ควรเก็บไว้ในโฟลเดอร์ Downloads หรือ OneDrive (อาจถูกลบ/ย้าย)
  4. ตั้งให้เปิดเองอัตโนมัติ (แนะนำ)
    ในโฟลเดอร์ C:\HumLai-Print-Server ดับเบิลคลิก install-autostart.bat
    ครั้งแรกจะติดตั้งส่วนประกอบ 1–3 นาที แล้วขึ้นคำว่า เสร็จสิ้น — จากนี้ Print Server จะเปิดเองทุกครั้งที่เปิดเครื่อง ทำงานเบื้องหลังไม่มีหน้าต่าง และถ้าดับเองจะเปิดใหม่ให้ภายใน 5 วินาที
    ถ้า Windows ขึ้น “Windows protected your PC” กด More info → Run anyway (ไฟล์ .bat มาจากระบบของร้านเอง)
    ถ้า Windows Firewall ถามสิทธิ์ให้ Node.js ติ๊ก Private networks แล้วกด Allow access — จำเป็นถ้าจะสั่งพิมพ์จากแท็บเล็ต/เครื่องอื่นในร้าน

    ถ้าไม่อยากให้เปิดอัตโนมัติ ใช้ start-printer.bat แทน (ต้องเปิดเองทุกครั้ง และห้ามปิดหน้าต่างดำ)

  5. เชื่อมหน้าเว็บกับ Print Server
    กลับไปหน้า ตั้งค่าเครื่องพิมพ์ (เปิดจากเครื่องเดียวกับที่ติดตั้ง) → กด ตรวจสอบอีกครั้ง
    กล่อง Print Server ต้องขึ้นสีเขียว เชื่อมต่อแล้ว และที่อยู่เป็น http://127.0.0.1:3001
    ถ้าขึ้นสีแดง “ถูกเบราว์เซอร์บล็อก” กดปุ่ม ใช้ http://127.0.0.1:3001 แทน ในกล่องนั้น — หน้าเว็บ https ติดต่อได้เฉพาะ Print Server ในเครื่องเดียวกัน Chrome อาจถามสิทธิ์ “เข้าถึงอุปกรณ์ในเครือข่าย” ให้กด อนุญาต

4. ตั้งค่าและทดสอบเครื่องพิมพ์

  1. กด 🔍 ค้นหาเครื่องพิมพ์ในวงแลน — ระบบสแกนหาเครื่องที่เปิดพอร์ต 9100 (ใช้เวลาไม่เกิน 1 นาที)
  2. กด เพิ่ม ที่เครื่องที่ต้องการ แล้วตั้ง ชื่อ และ ประเภท (ใบเสร็จ / ครัว / บาร์)
    สแกนเจอหลายเครื่อง ไม่แน่ใจว่าเครื่องไหน? ปิดเครื่องพิมพ์ → กดปุ่ม FEED ค้างไว้ → เปิดเครื่อง → ปล่อยปุ่มเมื่อกระดาษเริ่มออก เครื่องจะพิมพ์ใบ Self-test ที่มี IP Address ของตัวเอง เอา IP นั้นมาใส่ให้ตรง
  3. กด ทดสอบพิมพ์ ใต้เครื่องพิมพ์แต่ละเครื่อง — ใต้ปุ่มจะแสดงผลทีละขั้น (ดูหัวข้อถัดไป)
  4. กด บันทึกการตั้งค่า
  5. ถ้าต้องการให้ออเดอร์ที่ลูกค้าสั่งผ่าน QR พิมพ์ใบครัวเอง กด เปิดการพิมพ์อัตโนมัติ ในกล่อง “พิมพ์ออเดอร์ลูกค้าสั่งเอง (QR) อัตโนมัติ”

5. อ่านสถานะการพิมพ์

ทุกครั้งที่สั่งพิมพ์ จะมีกล่องสถานะขึ้นที่มุมล่างขวาของจอ และปุ่มทดสอบพิมพ์จะแสดงรายการขั้นตอนใต้ปุ่ม

กล่องสถานะความหมาย
🟢 พิมพ์เสร็จแล้ว ✓เครื่องพิมพ์ยืนยันว่าพิมพ์ออกแล้ว (กล่องหายเองใน 4 วินาที)
🟡 ส่งถึงเครื่องพิมพ์แล้ว — ไม่ได้รับการยืนยันงานไปถึงเครื่องแล้ว แต่เครื่องรุ่นนี้ไม่ตอบกลับ ให้ดูที่เครื่องว่ากระดาษออกไหม
🔴 พิมพ์ไม่ออก ✕ค้างไว้จนกดปิด บอกว่าติดที่ขั้นไหน พร้อมวิธีแก้

5 ขั้นของการพิมพ์ — ติดขั้นไหน แก้ตรงนั้น

ขั้นตรวจอะไรถ้าขึ้น ✕ ให้แก้
1. หน้าเว็บ → Print ServerPrint Server เปิดอยู่และหน้าเว็บติดต่อได้ดับเบิลคลิก restart-print-server.bat หรือ start-printer.bat · ตรวจที่อยู่ Print Server (ข้อ 3.5)
2. Print Server → เครื่องพิมพ์ต่อเข้า IP ของเครื่องพิมพ์ได้เครื่องพิมพ์เปิดอยู่ไหม · สายแลนแน่นไหม · IP ถูกไหม (พิมพ์ Self-test ดู)
3. เครื่องพิมพ์พร้อมกระดาษ / ฝา / ข้อผิดพลาดของเครื่องใส่กระดาษ · ปิดฝาให้สนิท · ปิด-เปิดเครื่องพิมพ์
4. ส่งงานพิมพ์ข้อมูลส่งถึงเครื่องครบปิด-เปิดเครื่องพิมพ์แล้วสั่งใหม่
5. ยืนยันพิมพ์เสร็จเครื่องตอบกลับหลังพิมพ์จบ! = เครื่องไม่ตอบ ให้ดูที่เครื่อง · “กระดาษหมดระหว่างพิมพ์” = ใส่กระดาษ เครื่องจะพิมพ์ต่อเอง
ขั้น 3 ขึ้น ! “อุปกรณ์ที่ IP นี้ไม่ตอบสถานะแบบเครื่องพิมพ์ใบเสร็จ” มักแปลว่าใส่ IP ผิดเครื่อง (เช่นไปโดนเครื่องพิมพ์เอกสารหรืออุปกรณ์อื่นที่เปิดพอร์ต 9100) ให้พิมพ์ Self-test เพื่อดู IP จริง

6. อัปเดตเวอร์ชันใหม่

หน้า ตั้งค่าเครื่องพิมพ์ จะขึ้นแถบสีเหลือง “มี Print Server เวอร์ชันใหม่” เมื่อเครื่องในร้านยังใช้เวอร์ชันเก่า

  1. กด ⬇️ ดาวน์โหลด Print Server ได้ไฟล์ zip ใหม่
  2. คลิกขวา → Extract All… → เลือก C:\ ที่เดิม → ถ้าถามว่าแทนที่ไฟล์ไหม กด Replace the files in the destination
  3. ในโฟลเดอร์ C:\HumLai-Print-Server ดับเบิลคลิก restart-print-server.bat
  4. กลับไปหน้าตั้งค่าเครื่องพิมพ์ → กด ตรวจสอบอีกครั้ง → เลขเวอร์ชันต้องเป็นตัวใหม่
ค่าที่ตั้งไว้ไม่หาย การตั้งค่าพิมพ์อัตโนมัติเก็บอยู่ในไฟล์ print-auto-config.json ซึ่งไม่อยู่ใน zip จึงไม่ถูกเขียนทับ

7. แก้ปัญหาที่พบบ่อย

เครื่องมือแรกที่ควรใช้: ดับเบิลคลิก check-printer.bat — ตรวจ Node.js, ส่วนประกอบ, พอร์ต 3001 และแสดง log ล่าสุดให้

อาการสาเหตุ / วิธีแก้
หน้าเว็บขึ้น “ไม่พบ Print Server”Print Server ไม่ได้เปิด → restart-print-server.bat · ถ้ายังไม่ได้ ดู logs\print-server.log หรือรัน check-printer.bat
“ถูกเบราว์เซอร์บล็อก”หน้าเว็บ https ติดต่อ IP วงแลนไม่ได้ → ใช้ 127.0.0.1:3001 และเปิดหน้าเว็บจากเครื่องที่ติดตั้ง Print Server
ติดตั้งแล้วขึ้น “ไม่พบ Node.js”ติดตั้ง Node.js ก่อน (ข้อ 3.1) แล้วปิดหน้าต่างเดิม เปิด .bat ใหม่ (หรือรีสตาร์ตเครื่อง)
“ติดตั้งส่วนประกอบไม่สำเร็จ”เครื่องไม่ได้ต่ออินเทอร์เน็ต หรือ Firewall/Antivirus บล็อก npm → ต่อเน็ตแล้วลองใหม่
ทดสอบพิมพ์สำเร็จแต่กระดาษไม่ออกIP ผิดเครื่อง → พิมพ์ Self-test (กด FEED ค้างตอนเปิดเครื่อง) แล้วแก้ IP
“ติดต่อเครื่องพิมพ์ไม่ได้ภายใน 5 วินาที”เครื่องพิมพ์ปิด / สายหลุด / IP เปลี่ยน (เราเตอร์แจก IP ใหม่) → ตั้ง IP ของเครื่องพิมพ์ให้คงที่
“กระดาษหมด” / “ฝาเปิดอยู่”ใส่กระดาษ ปิดฝาให้สนิท แล้วสั่งพิมพ์ใหม่
ภาษาไทยออกมาเป็นตัวแปลกตั้งชุดตัวอักษรของเครื่องพิมพ์เป็นภาษาไทย (Code page Thai) ด้วยโปรแกรมของยี่ห้อเครื่องพิมพ์
QR สั่งแล้วใบครัวไม่ออกดูกล่อง “พิมพ์ออเดอร์ลูกค้าสั่งเอง (QR) อัตโนมัติ” ว่ากำลังทำงาน และกด “ส่งรายการเครื่องพิมพ์ล่าสุดไปให้ Print Server”

8. ไฟล์ในโฟลเดอร์

ไฟล์ใช้ทำอะไร
install-autostart.batติดตั้งส่วนประกอบ + ตั้งให้เปิดเองทุกครั้งที่เปิดเครื่อง (ใช้ครั้งเดียว)
start-printer.batเปิด Print Server แบบมีหน้าต่าง (ปิดหน้าต่าง = หยุดทำงาน)
restart-print-server.batปิด-เปิด Print Server ใหม่ ใช้หลังอัปเดต
check-printer.batตรวจหาสาเหตุเมื่อ Print Server ไม่ทำงาน
uninstall-autostart.batยกเลิกการเปิดอัตโนมัติ
print-server-daemon.vbsตัวเฝ้าที่รันเบื้องหลัง (ไม่ต้องเปิดเอง)
server.js, print-ticket.js, printer-net.js, auto-print.jsตัวโปรแกรม Print Server
logs\print-server.logบันทึกการทำงาน (เกิดขึ้นหลังเปิดอัตโนมัติ) — ส่งให้ผู้ดูแลเมื่อมีปัญหา
print-auto-config.jsonค่าการพิมพ์อัตโนมัติที่หน้าเว็บส่งมา (สร้างเอง ห้ามลบ)

9. ถอนการติดตั้ง

  1. ดับเบิลคลิก uninstall-autostart.bat — หยุด Print Server และยกเลิกการเปิดอัตโนมัติ
  2. ลบโฟลเดอร์ C:\HumLai-Print-Server
หมายเหตุ uninstall-autostart.bat ปิดโปรแกรม Node.js ทุกตัวในเครื่อง ถ้าเครื่องนี้รัน API Server ด้วย ต้องเปิด API Server ใหม่
