เครื่อง POS ที่ติดตั้งโปรแกรม HumLai-POS  ·  ยี่ห้อ/รุ่น ..................................
■ Administrator: Command Prompt—  ☐  ✕
Microsoft Windows [Version ..........] (c) Microsoft Corporation. All rights reserved. C:\Windows\system32>wmic bios get serialnumber SerialNumber XXXXXXXXXX C:\Windows\system32>_
ภาพที่ 1  คำสั่ง wmic (Windows 10 / Windows 11 รุ่นที่ยังมี wmic)
■ Administrator: Windows PowerShell—  ☐  ✕
PS C:\Windows\system32> gcim Win32_BIOS | select SerialNumber SerialNumber ------------ XXXXXXXXXX PS C:\Windows\system32> _
ภาพที่ 2  คำสั่ง PowerShell (ใช้แทนเมื่อเครื่องไม่มีคำสั่ง wmic)
วิธีตรวจสอบ
  1. คลิกขวาที่ Start เลือก Terminal (Admin) หรือค้นหา cmd แล้วเลือก Run as administrator
  2. พิมพ์คำสั่งตามภาพที่ 1 หรือภาพที่ 2 แล้วกด Enter
  3. หมายเลขที่แสดงต้องตรงกับ Serial Number ที่ระบุในคำขอ และตรงกับป้ายที่ตัวเครื่อง (CPU)
  4. แคปหน้าจอจริงจากเครื่อง POS มาแนบแทนภาพตัวอย่างนี้
