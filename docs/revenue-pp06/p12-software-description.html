HumLai-POS Program

คุณสมบัติโปรแกรม / Software Description

  1. เป็นโปรแกรมบนเครื่องคอมพิวเตอร์ ใช้บันทึกรายการขายสินค้าและบริการของร้านอาหาร
  2. ถูกต้อง เที่ยงตรง ในการพิมพ์ใบเสร็จรับเงิน/ใบกำกับภาษี และรายงานการขายตามที่กรมสรรพากรกำหนด ออกใบกำกับภาษีอย่างย่อ (มาตรา 86/6) และแบบเต็มรูป (มาตรา 86/4) ได้ในเครื่องเดียวกัน และพิมพ์เลขรหัสประจำเครื่อง (POS ID) ที่อธิบดีกรมสรรพากรกำหนดในใบกำกับภาษีอย่างย่อได้
  3. ใบกำกับภาษีอย่างย่อมีคำว่า "TAX INV (ABB)" รหัส V กำกับสินค้าที่เสียภาษี และข้อความ "ราคารวมภาษีมูลค่าเพิ่มแล้ว (VAT Included)"
  4. เลขที่ใบกำกับภาษีอย่างย่อเรียงต่อเนื่องตามลำดับการขาย เลขที่ใบกำกับภาษีเต็มรูปออกโดยเครื่องควบคุมกลาง เรียงต่อเนื่อง ไม่ซ้ำ
  5. มีวัน เดือน ปี และเวลากำกับในใบเสร็จรับเงิน/ใบกำกับภาษีทุกใบ
  6. รายงานปิดยอดประจำวัน และรายงานภาษีขาย แสดงมูลค่าสินค้า ภาษี และเลขที่ใบกำกับภาษีใบแรก-ใบสุดท้าย
  7. ง่ายต่อการตรวจสอบ บิลที่ยกเลิกไม่ถูกลบออกจากระบบ (ดูได้ในรายงานประวัติการยกเลิก) ใบกำกับภาษีที่ยกเลิกเก็บเวลาและเหตุผลการยกเลิกไว้
  8. ควบคุมรายการสั่งอาหารของแต่ละโต๊ะ แสดงรายการอาหาร โต๊ะ และเวลาที่สั่ง
  9. กำหนดเมนู หมวดหมู่ และราคาขายแยกตามประเภทการขาย (ทานที่ร้าน / ห่อกลับบ้าน / Delivery) และแยกตามสาขาได้
  10. พิมพ์ใบสั่งอาหารไปยังครัวหรือบาร์โดยอัตโนมัติตามหมวดของเมนู
  11. กำหนดส่วนลดได้หลายรูปแบบ เช่น ลดเป็นเปอร์เซ็นต์ ลดเป็นจำนวนเงิน และกำหนดหมวดเมนูที่ลดได้ รวมถึงกำหนดค่าบริการ (Service Charge) และอัตราภาษีมูลค่าเพิ่ม
  12. รับชำระเงินสด เงินโอน / QR PromptPay บัตรเครดิต และแยกชำระหลายช่องทางในบิลเดียว
  13. ลูกค้าสแกน QR สั่งอาหารเองได้ บิลออกเมื่อพนักงานยืนยันยอดชำระ
  14. บันทึกสูตรวัตถุดิบ (BOM) ตัดสต็อกตามยอดขาย และบันทึกรายการของเสีย (Waste)
  15. ข้อมูลการขายบันทึกที่ฐานข้อมูล SQL Server ของเครื่องควบคุมกลางทันทีที่ชำระเงิน และสำรองข้อมูล (Backup) เก็บไว้ได้
  16. การเข้าทำงานต้องผ่านรหัสผ่านประจำตัวพนักงาน แบ่งสิทธิ์พนักงาน / แคชเชียร์ / ผู้ดูแลระบบ
  17. ใช้ได้ทั้งจอสัมผัส (Touch Screen) และคีย์บอร์ด
  18. รายงานต่าง ๆ แสดงบนจอภาพ ส่งออกเป็นไฟล์ (Excel) และพิมพ์รายงานปิดยอดออกเครื่องพิมพ์ได้
  19. ใบกำกับภาษีพิมพ์บนกระดาษความร้อนม้วนเดียว สำเนาจัดเก็บในรูปแบบข้อมูลอิเล็กทรอนิกส์
  20. รองรับหลายสาขา แยกข้อมูลการขาย เลขที่บิล และเครื่องพิมพ์ตามสาขา
