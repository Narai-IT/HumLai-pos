ระบบ HumLai-POS  ·  พิมพ์ผ่าน Print Server ออกเครื่องพิมพ์ความร้อน 80 มม. (32 ตัวอักษรต่อบรรทัด)
ใบกำกับภาษีอย่างย่อที่ระบบพิมพ์

เทียบกับรายการที่ต้องแสดง (แบบ ค.ก.๔ ก ข้อ 2.4)

รายการที่ต้องแสดงบนใบ
ชื่อผู้ประกอบการ และเลขผู้เสียภาษีหัวใบ
คำว่า "ใบกำกับภาษีอย่างย่อ" / TAX INV (ABB)หัวใบ
เลขรหัสประจำเครื่อง (POS ID) ที่สรรพากรกำหนดหัวใบ
เลขที่ใบเรียงต่อเนื่องเลขที่
วัน เดือน ปี และเวลาDate
ชื่อ ชนิด จำนวน และมูลค่าสินค้ารายการอาหาร
รหัสแยกสินค้าเสียภาษี (V)ท้ายราคา
ข้อความ "ราคารวมภาษีมูลค่าเพิ่มแล้ว" (VAT Included)ท้ายใบ

ระบบพิมพ์แบบนี้เมื่อสาขาตั้งเลขผู้เสียภาษีไว้ที่ หลังบ้าน > สาขา และพิมพ์ POS ID ตามที่กรอกในช่อง "เลขรหัสประจำเครื่อง POS"

ข้อความหัวใบ (ชื่อร้าน ที่อยู่ โทร เลขผู้เสียภาษี ข้อความท้ายใบ) ตั้งที่ หลังบ้าน > สาขา
เลขที่ = รหัสบิลของสาขา-#ลำดับ เรียงต่อเนื่องตามสาขา
