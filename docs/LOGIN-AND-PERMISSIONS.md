# ล็อกอินและสิทธิ์การใช้งาน

รหัสพนักงานเช็กที่เซิร์ฟเวอร์ ไม่ส่งไปที่เบราว์เซอร์อีกแล้ว ล็อกอินสำเร็จได้ token อายุ 12 ชั่วโมง
หน้าเว็บแนบ token ไปกับทุกคำขอให้เอง

**API ตรวจสิทธิ์เมื่อเปิด "บังคับล็อกอินทุกเครื่อง" เท่านั้น** (หลังบ้าน → ตั้งค่าร้าน)
ปิดอยู่ = ใครรู้ที่อยู่ API ก็เรียกได้เหมือนเดิม รวมถึงดูรหัสพนักงานผ่านหน้าพนักงาน — ควรเปิดทันทีที่แจกรหัสครบ

## ใครทำอะไรได้ (เมื่อเปิดบังคับล็อกอิน)

| กลุ่ม | ใคร | ทำได้ |
| --- | --- | --- |
| ไม่ต้องล็อกอิน | ลูกค้าสแกน QR, Print Server | ดูเมนู สั่งและจ่ายผ่าน QR ดึงคิวใบครัว |
| พนักงานทั่วไป | สิทธิ์ "พนักงานทั่วไป" | ขาย เปิด/ปิดโต๊ะ เช็กบิล ของเสีย ฝากเหล้า — เฉพาะสาขาตัวเอง |
| แคชเชียร์ | สิทธิ์ "แคชเชียร์" | ทุกอย่างของพนักงาน + ผังโต๊ะ รับวัตถุดิบ ดูสต็อก |
| ผู้จัดการสาขา | แอดมิน ที่ผูกกับสาขาเดียว (ไม่ใช่สาขาหลัก) | + ปริ้นเตอร์และเมนูรายสาขา **ของสาขาตัวเอง** |
| แอดมินสำนักงานใหญ่ | แอดมิน ที่สาขาเป็น "ทุกสาขา" หรือสาขาหลัก | ทุกอย่าง: สาขา พนักงาน ตั้งค่าร้าน เมนูกลาง หมวดหมู่ ส่วนลด BOM ล้างข้อมูล |

- พนักงานที่ผูกสาขาเดียว ส่งคำขอของสาขาอื่นมาไม่ได้ — เซิร์ฟเวอร์ใช้สาขาใน token เสมอ
- ใส่รหัสผิด 5 ครั้งติดกัน ผู้ใช้นั้นถูกล็อก 5 นาที
- token หมดอายุ / ถูกยกเลิก → หน้าเว็บพากลับหน้าล็อกอินเอง

## กุญแจเซ็น token

ไม่ต้องตั้งอะไร — ครั้งแรกระบบสุ่มกุญแจเก็บในตาราง Settings (`api_secret`)
ต้องการกำหนดเอง ใส่ `API_SECRET=...` ใน `.env` ของเครื่อง API
เปลี่ยนกุญแจ = token เดิมใช้ไม่ได้ทั้งหมด ทุกเครื่องต้องล็อกอินใหม่ (ใช้ตอนสงสัยว่า token รั่ว)
