# พิมพ์จากแท็บเล็ต Android / iPad (กล่องพิมพ์ของสาขา)

แท็บเล็ตสั่งเครื่องพิมพ์ในร้านตรง ๆ ไม่ได้ (เบราว์เซอร์บล็อก) จึงส่งงานพิมพ์ไปเข้าคิวที่ API พร้อมรหัสสาขา
แล้ว **กล่องพิมพ์** ของสาขานั้น (Print Server ที่เปิดค้างไว้ในร้าน) ดึงไปพิมพ์ทุก ~1.5 วินาที และรายงานผลกลับ

- แท็บเล็ตขึ้นแจ้งมุมจอทุกงาน: **กำลังพิมพ์ → พิมพ์สำเร็จ / พิมพ์ไม่สำเร็จ** (พร้อมเหตุผลและปุ่ม "ลองพิมพ์ใหม่")
- งานที่กล่องพิมพ์ไม่ได้รับภายใน 30 วินาที (กล่องปิด/เน็ตหลุด) ถูกยกเลิก ไม่พ่นใบเก่าออกมาทีหลัง
- ออกเครื่องพิมพ์ตามที่ตั้งไว้ของสาขา (ใบเสร็จ ครัว บาร์) เหมือนพิมพ์จากคอม

## ตั้งค่าครั้งเดียว

### 1. เครื่อง API (ร้านหลัก)
ใส่ใน `D:\humlai-pos\.env` (ตั้งรหัสยาว ๆ เอง ห้ามบอกคนนอก):
```
PRINT_AGENT_KEY=ตั้งรหัสยาวอย่างน้อย 20 ตัว
```
แล้วรัน `update-api.bat` แบบ Administrator (สร้างตาราง `PrintJobs`, `PrintAgents` และโหลดรหัสใหม่)

### 2. กล่องพิมพ์ที่สาขา (คอม Windows / Mini PC ที่เปิดค้าง วงแลนเดียวกับเครื่องพิมพ์)
1. ติดตั้งและเปิด Print Server แบบเดิม (`start-printer.bat` / `install-autostart.bat`) — อัปเดตด้วย `update-printer.bat`
2. เปิดหน้า POS บนเครื่องนี้ ล็อกอินด้วยผู้ใช้ของสาขานั้น → หลังบ้าน → **ตั้งค่าเครื่องพิมพ์**
3. ตั้งเครื่องพิมพ์ของสาขาให้ครบแล้วกดบันทึก
4. หัวข้อ **ให้เครื่องนี้เป็นกล่องพิมพ์ของสาขา** → ใส่รหัสกล่องพิมพ์ (ค่าเดียวกับ `PRINT_AGENT_KEY`) → **เปิดรับงานจากแท็บเล็ต**

### 3. แท็บเล็ตแต่ละเครื่อง
หลังบ้าน → ตั้งค่าเครื่องพิมพ์ → **โหมดพิมพ์ของเครื่องนี้** → เลือก **ส่งผ่านกล่องพิมพ์ของสาขา**
ต้องเห็นกล่องพิมพ์ของสาขาเป็น "ออนไลน์" แล้วกด "ทดสอบพิมพ์" ที่เครื่องพิมพ์สักเครื่อง

## ตรวจปัญหา
- แท็บเล็ตขึ้น "กล่องพิมพ์ของสาขาไม่ได้รับงาน…" → กล่องพิมพ์ปิดอยู่ / เน็ตหลุด / ยังไม่ได้เปิดรับงาน
- กล่องพิมพ์ขึ้น "รหัสกล่องพิมพ์ไม่ถูกต้อง" → รหัสไม่ตรงกับ `PRINT_AGENT_KEY` ในเครื่อง API
- "เชื่อมต่อเครื่องพิมพ์ … ไม่ได้" → เครื่องพิมพ์ดับ / IP เปลี่ยน (ตั้งค่าที่กล่องพิมพ์)
- กล่องพิมพ์ต้องใช้ Node.js 18 ขึ้นไป
