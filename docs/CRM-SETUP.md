# เชื่อม POS กับระบบสมาชิก (CRM)

POS ส่งบิลที่ชำระแล้วไประบบสมาชิกที่ `crm.naraipizzeria.com` เพื่อให้แต้มลูกค้า และให้ CRM รู้ยอดขายสมาชิก

- **หน้าขาย (ปิดบิล):** มีช่อง "สมาชิก" ให้สแกน QR บัตรสมาชิกใน LINE (เครื่องยิงบาร์โค้ด USB ใช้ได้เลย) หรือพิมพ์เบอร์โทร/เลขสมาชิก แล้วกด Enter
- **หน้าลูกค้าสแกน QR สั่งเอง:** จอแรกมีช่องใส่เลขสมาชิกหรือเบอร์โทร (ไม่บังคับ) ได้แต้มตอนพนักงานกดยืนยันยอดโอน
- **ใบเสร็จ:** มีบรรทัดเลขสมาชิกและแต้มที่ได้ ลูกค้าได้ข้อความ LINE แจ้งแต้มด้วย
- **ทุกบิล** ถูกส่งไป CRM รวมบิลที่ไม่ใช่สมาชิก (ไม่ผูกกับใคร) เพื่อดูสัดส่วนยอดขายสมาชิก
- **แต้ม** คิดจากยอดหลังส่วนลด ก่อนค่าบริการและ VAT ตามกฎแต้มที่ตั้งในหลังบ้าน CRM

ไม่ตั้งค่าส่วนนี้ = POS ทำงานเหมือนเดิมทุกอย่าง ไม่มีช่องสมาชิกขึ้น

## คูปองและแลกแต้ม

- **หน้าขาย:** สแกนสมาชิกแล้วจะเห็นคูปองของลูกค้า (บอกว่าใช้กับบิลนี้ได้ไหม ลดเท่าไร) และของรางวัลที่แต้มพอแลก
  - กด **ใช้** → คูปองเป็นส่วนลดของบิล (ใช้แทนส่วนลดร้าน 1 บิล 1 ส่วนลด)
  - กด **แลก xx แต้ม** → ตัดแต้มทันที ได้คูปองแล้วใช้กับบิลนี้เลย
- **หน้าลูกค้าสั่งเอง:** หน้าตะกร้ามีการ์ด "คูปองและแต้มของคุณ" ต้องยืนยันตัวตนก่อน โดยเปิดบัตรสมาชิกใน LINE แล้วพิมพ์รหัส 6 หลักใต้ QR (เปลี่ยนทุกนาที)
  แล้วใช้คูปอง/แลกแต้มได้ ยอดในตะกร้าและยอด QR พร้อมเพย์ลดตามคูปองทันที
- **คูปองถูกจองไว้กับบิลที่กำลังเปิด** ใช้ซ้ำกับบิลอื่นไม่ได้ ตัดคูปองตอนบิลชำระแล้ว (หน้าลูกค้า = ตอนพนักงานยืนยันยอดโอน)
  ปิดบิลไม่จ่ายหรือเปลี่ยนใจ คูปองคืนให้ลูกค้าเอง (หน้าขาย 30 นาที · หน้าลูกค้า 2 ชั่วโมง)
- **แต้มที่แลกแล้วไม่คืน** ถ้าไม่จ่ายบิลนั้น ลูกค้ายังมีคูปองไว้ใช้ครั้งหน้า (ดูได้ในบัตรสมาชิก LINE)
- รหัสยืนยันไม่ส่งข้อความ LINE จึงไม่ใช้โควต้าข้อความของ OA
- ข้อความแจ้งแต้มหลังชำระบิลปิดไว้เป็นค่าเริ่มต้น (นับโควต้าข้อความ) เปิดได้ที่หลังบ้าน CRM → กฎแต้ม → "แจ้งแต้มทาง LINE หลังชำระบิล"

## เน็ตหลุดหรือ CRM ปิดอยู่

- ขายต่อได้ตามปกติ บิลบันทึกใน POS ก่อนเสมอ
- บิลเข้าคิว (ตาราง `CrmBills`) แล้ว API ส่งซ้ำเองทุก 1 นาที CRM กันบิลซ้ำด้วยเลขบิล ส่งซ้ำได้ไม่ได้แต้มซ้ำ
- ใบเสร็จบิลสมาชิกพิมพ์ว่า "แต้ม: เข้าบัญชีภายหลัง แจ้งทาง LINE"
- ดูคิว: เปิด `<API>/api/pos?action=getCrmStatus` ตอนล็อกอินอยู่ (หรือดูตาราง `dbo.CrmBills` ใน SQL Server)

## ตั้งค่า (ทำครั้งเดียว)

### 1. ออกกุญแจ POS จากเครื่อง CRM

ที่เครื่อง CRM (PowerShell แบบ Admin) ออกกุญแจให้แต่ละสาขา โดยใช้รหัสสาขาใน CRM:

```powershell
cd C:\apps\Crm\server
node --env-file=.env scripts/manage.js pos-key HL01
```

จดกุญแจที่ขึ้นมา (`crm_...`) ระบบแสดงครั้งเดียว กุญแจผูกกับสาขาใน CRM บิลที่ส่งด้วยกุญแจนี้จะลงสาขานั้น

### 2. ให้เครื่อง POS ผ่าน Cloudflare Access

CRM อยู่หลัง Cloudflare Access ต้องให้เครื่อง POS มี Service Token:

1. Cloudflare Zero Trust → **Access** → **Service credentials** (หรือ Service Auth) → **Create Service Token** ตั้งชื่อ `humlai-pos`
2. จด **Client ID** และ **Client Secret** (Secret แสดงครั้งเดียว)
3. **Access** → **Applications** → แอปของ `crm.naraipizzeria.com` → **Policies** → **Add a policy**
   - Action: **Service Auth**
   - Include: **Service Token** → `humlai-pos`

### 3. ใส่ค่าใน `.env` ของเครื่อง API (`D:\humlai-pos\.env`)

```
CRM_URL=https://crm.naraipizzeria.com
CRM_KEYS='{"XUM":"crm_xxxxxxxx"}'
CRM_ACCESS_CLIENT_ID=xxxxxxxx.access
CRM_ACCESS_CLIENT_SECRET=xxxxxxxx
```

- `CRM_KEYS` คือ `{"รหัสสาขาใน POS":"กุญแจจากข้อ 1"}` ดูรหัสสาขาใน POS ได้ที่หลังบ้าน POS → สาขา
- หลายสาขา: `'{"XUM":"crm_aaa","XUM2":"crm_bbb"}'`
- มีสาขาเดียวใส่ `'{"*":"crm_xxx"}'` ได้
- ต้องเป็น JSON บรรทัดเดียวและครอบด้วย `' '`

### 4. อัปเดตและเปิด API ใหม่

ดับเบิลคลิก `update-api.bat` (ดึงโค้ดใหม่ สร้างตาราง `CrmBills` ด้วย `sql:init` แล้วเปิด API ใหม่)

### 5. ตรวจ

- เปิด `<API>/api/pos?action=ping` ต้องเห็น `"crm":true`
- หน้าขาย กดชำระเงิน ต้องเห็นช่อง "สมาชิก (สะสมแต้ม)"
- ลองสแกน QR บัตรสมาชิกของตัวเอง ปิดบิล แล้วดูว่า LINE แจ้งแต้มเข้า และหลังบ้าน CRM → สมาชิก มีแต้มเพิ่ม

## ความปลอดภัย

- กุญแจ CRM อยู่ใน `.env` ของเครื่อง API เท่านั้น หน้าเว็บไม่เคยเห็น
- คำสั่งค้นหาสมาชิกของพนักงาน (`crmMemberLookup`) ต้องล็อกอินเสมอ แม้ไม่ได้เปิด "บังคับล็อกอิน"
- หน้าลูกค้าค้นได้แค่ชื่อย่อ (เช่น `สม***`) และจำกัดจำนวนครั้งต่อนาที กันการไล่เดาเบอร์
